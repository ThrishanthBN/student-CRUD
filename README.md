# student-CRUD
Title: Student CRUD Application

Stack:
- HTML
- CSS
- JavaScript
- Node.js
- Express
- MongoDB

Database:
DB Name: student_crud
Collection Name: students

How to Run:
1. Run `npm install`
2. Run `npm start`
3. Open http://localhost:3000

Description:
This application allows adding, updating, viewing, and deleting student records.
